DATA FLOW VERIFICATION
================================================================================

Document Parsing:
  Reads .txt files from source directory
  Reads .pdf files from source directory
  Extracts metadata from filenames
  Validates against allowed values
  Outputs JSON with structured chunks

Chunking:
  Fixed-size: 500 chars with 50 char overlap
  Semantic: NLP-based sentence-aware chunking
  UUID generation for each chunk
  Position tracking (start_pos, end_pos)

Embedding:
  Loads chunks from ingestion output
  Uses sentence-transformers (all-MiniLM-L6-v2)
  Generates 384-dimensional vectors
  Batch processing for efficiency
  Error handling and logging

Storage:
  Qdrant collection creation
  Vector storage with metadata
  Cosine similarity indexing
  Payload includes all metadata

Search:
  Dense search (vector similarity)
  Sparse search (BM25 ranking)
  Hybrid scoring (0.6*dense + 0.4*sparse)
  Metadata filtering
  Result ranking

Query Interface:
  ask() function with print option
  Pipeline.query() with advanced options
  Result formatting with confidence scores
  Filtering support
